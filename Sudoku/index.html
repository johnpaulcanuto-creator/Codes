    How to Play Sudoku

    1

    Fill the grid so that every row, column, and 3x3 box contains the digits 1-9.

    2

    No number can be repeated in any row, column, or 3x3 box.

    3

    Use the notes feature to mark possible numbers for a cell by toggling the Notes button.

    4

    Click the hint button if you get stuck. You have limited hints per game.

    Follow all standard Sudoku rules (rows, columns, 3x3 boxes must contain 1-9 without repetition).

    3

    The numbers in each cage must sum up to the small number in its corner.

    5
